# Manual installation

1. Close LumeView if running.
2. Extract the LumeView folder from the ZIP. Do not run the app inside the ZIP.
3. Suggested location: %LOCALAPPDATA%\Programs\LumeView.
   Press Win+R, open %LOCALAPPDATA%\Programs, and place the LumeView folder there.
   Create Programs if necessary. Another writable folder is also suitable.
4. Run lumeview.exe. Keep the tools folder beside the executable.
5. Optionally create a desktop shortcut to lumeview.exe.

MANUAL FILE ASSOCIATIONS
Right-click an image > Open with > Choose another app > choose an app on your PC.
Select lumeview.exe and choose Always. Repeat for each desired format (JPG, PNG,
WebP, CBZ, etc.). Windows labels may vary. Alternatively use Settings > Apps > Default apps.
This package does not register custom file-type icons.

UPDATE: close the app and extract the new version into the same folder.
REMOVE: select another default app, close LumeView, and delete its folder and shortcuts.

Extraction does not modify the Registry or create file associations or shortcuts.
This ZIP contains no installation scripts. The application is unsigned;
ZIP packaging does not guarantee the absence of antivirus alerts.

## Português

1. Feche o LumeView se estiver aberto.
2. Extraia a pasta LumeView do ZIP. Não execute o programa dentro do ZIP.
3. Local sugerido: %LOCALAPPDATA%\Programs\LumeView.
   Pressione Win+R, abra %LOCALAPPDATA%\Programs e coloque a pasta LumeView nela.
   Crie a pasta Programs se necessário. Outra pasta com permissão de escrita também serve.
4. Execute lumeview.exe. Mantenha a pasta tools junto do executável.
5. Opcional: crie um atalho para lumeview.exe na área de trabalho.

ASSOCIAÇÕES MANUAIS
Botão direito em uma imagem > Abrir com > Escolher outro aplicativo > procurar
um aplicativo no computador. Selecione lumeview.exe e escolha Sempre.
Repita para cada formato desejado (JPG, PNG, WebP, CBZ etc.). Os nomes dos comandos
variam conforme o Windows. Alternativa: Configurações > Aplicativos > Aplicativos padrão.
Ícones específicos de tipos de arquivo não são registrados por este pacote.

ATUALIZAR: feche o programa e extraia a nova versão sobre a mesma pasta.
REMOVER: escolha outro aplicativo padrão, feche o programa e exclua a pasta e seus atalhos.

A extração não altera o Registro nem cria associações ou atalhos automaticamente.
